# ChatApp client

Expo Router app (iOS, Android and web). See the [project README](../README.md) for setup.

- `app/` – screens (`index` is sign-in; `(app)/` holds the signed-in screens)
- `components/` – UI building blocks (conversation list, message bubble, composer, sheets)
- `lib/` – API client, auth/session handling, real-time chat store, theme and formatting
